Introduction

Booth's Multiplication Algorithm is a technique used in computer architecture to multiply signed binary numbers using 2's complement representation. It was developed by Andrew Donald Booth in 1951.


The algorithm reduces the number of addition and subtraction operations by examining pairs of bits. It is particularly useful when multiplying numbers containing consecutive 1s.

Algorithm Rules

Q0 Q-1 Operation
00No operation
01A = A + M
10A = A - M
11No operation

After checking the bits, perform an arithmetic right shift.
