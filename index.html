About Booth's Algorithm

Introduction

Booth's multiplication algorithm is used in Computer Organization and Architecture to multiply signed binary numbers. It uses 2's complement representation and reduces unnecessary arithmetic operations by examining pairs of multiplier bits.


Algorithm Rules

00

No operation

01

A = A + M

10

A = A - M

11

No operation


After each operation, an arithmetic right shift is performed on the combined A, Q and Q-1 registers. This process repeats for n iterations.

Advantages of Booth's Algorithm

• Supports signed binary multiplication.

• Uses 2's complement representation.

• Reduces unnecessary addition operations.

• Useful in arithmetic logic units.

• Efficient when the multiplier contains consecutive 1s.
